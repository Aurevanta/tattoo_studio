# Task: An accurate description, a share preview, robots.txt and a sitemap (audit 2026-10-08 SEO-02)

## 1. Problem / requested change

The audit of 2026-10-08, Sprint 0: "Corregir la meta descripción, añadir Open Graph, `robots.ts` y
`sitemap.ts`". The owner: "empieza". Evidence: INTENT.

## 2. Current behavior

The description advertised "Consulta guiada de tatuajes con OpenAI GPT-6 Astra", which is not
the engine the studio runs (the consultation is Claude, ADR-0026). There were no Open Graph or
Twitter tags, so a shared link had no preview. `/robots.txt` and `/sitemap.xml` were redirected
to `/entrar` by the page gate. Evidence: VERIFIED (`curl` on production, 2026-10-08).

## 3. Requirements

- **REQ-001** — The description says what the client receives and names no model or provider.
- **REQ-002** — A shared link shows a 1200 × 630 preview image built from the brand's own assets
  (`/brand/og.png`), with title and description.
- **REQ-003** — `/robots.txt` and `/sitemap.xml` are served without a session; crawlers may read
  only the public pages (`/entrar`, `/condiciones`, `/privacidad`) and are kept out of the rest.
- **REQ-004** — Page titles follow one pattern: «<page> · Inkcraft».

## 4. Acceptance criteria

- **AC-001** — `lib/site.test.ts` and `middleware.test.ts`: the description has no provider name;
  the Open Graph image is `/brand/og.png` on the site's base URL; the sitemap lists exactly the
  public pages, none of which is gated; robots disallows `/` and allows those pages; `/robots.txt`,
  `/sitemap.xml` and `/brand/og.png` are not gated.
- **AC-002** — A production build served locally answers `/robots.txt` and `/sitemap.xml` with
  200 and the expected content, and `/entrar` carries the description, Open Graph and Twitter tags.
