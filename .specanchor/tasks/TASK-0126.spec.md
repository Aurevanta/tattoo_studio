# Task: One vector per account and design

## 1. Current behaviour (OBSERVED, FINDING-0005)

`design_vector` had `design_id` as its primary key and `Studio.store_vector` wrote with
`INSERT OR REPLACE`. Storing the same design again (another version, or another account with
identical artwork) replaced the row: the previous vector file was left unreferenced until the
account was erased, and across accounts one account's row could replace another's, which then found
no vector (`load_vector` filters by owner). Since ADR-0043 a design without a vector cannot be
nudged, so losing it now refuses a size change.

## 2. Desired behaviour (INTENT, owner's audit list 2026-10-16, item 4)

«Aislar los vectores por usuario. Evitar que dos diseños idénticos de distintas cuentas compartan
una clave que pueda sobrescribirse y dejar archivos huérfanos.»

- **REQ-001**: the key is `(owner, design_id)`; an existing table is migrated on start, rows kept.
- **REQ-002**: a repeated store reuses the account's vector for that design (the design id is the
  hash of that geometry); a new one is stored only when none opens, and the dead row it replaces is
  erased. No vector file is left unreferenced.
- **REQ-003**: erasing versions never takes a vector a remaining version still shows: one stored
  under an upload about to be erased is re-homed first under a remaining version's reference.

## 3. Acceptance criteria (`app/tests/test_design_vector.py`)

- **AC-001** (REQ-001): two accounts with the same design keep a row and a file each; both load; erasing
  one account's design leaves the other's vector.
- **AC-002** (REQ-002): the same account storing the same design again keeps one vector file.
- **AC-003** (REQ-002): a vector whose file is gone is stored again and the dead ownership row goes.
- **AC-004** (REQ-001): a table keyed by `design_id` alone is migrated with its rows; the same design
  id can then be kept by a second account; reopening changes nothing.
- **AC-005** (REQ-003): erasing the design that stored a shared vector leaves it loadable for the
  other design, now under that design's reference.
- **AC-006**: `test_designs.py` (TASK-0116 erasure) still passes; ruff, format, mypy, pytest.
