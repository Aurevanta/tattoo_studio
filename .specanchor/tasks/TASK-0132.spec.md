# Task: The geometry corpus draws the same letters on every machine

## Problem

CI's «Python (services/worker)» job fails on `main` with one test,
`mockup/tests/test_corpus.py::test_the_local_limit_catches_redraws_the_global_one_misses`:
`lettering/light/letter_changed` and `lettering/dark/letter_changed` pass the local limit
(OBSERVED in the CI log of PR #4, 635 other tests passing; reproduced in the cloud session).

Cause (VERIFIED, measured): `mockup.corpus._font` used DejaVu Sans Bold when the system had it,
else Pillow's bundled font. The tolerance (0.21) was calibrated where DejaVu was absent — TASK-0087
records «redraws ≤ 0.202», which is the bundled font's 0.200–0.202 and not DejaVu's 0.385–0.389.
Linux runners have DejaVu, so the corpus measured a different letter there.

## Change

  calibration font, identical on every machine for the locked Pillow (12.3.0).

  tile limit, and the limit cannot be raised without refusing faithful finishes (lowest 0.231). The
  tolerance and `geometry.py` are unchanged; the miss is not claimed fixed.
